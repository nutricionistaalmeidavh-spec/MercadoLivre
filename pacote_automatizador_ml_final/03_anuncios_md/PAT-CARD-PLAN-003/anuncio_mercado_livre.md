# Template de Cardápio PAT com Cálculo Nutricional

## Título

Template de Cardápio PAT com Cálculo Nutricional

## Descrição

Modelo editável para organizar cardápios semanais e registrar informações nutricionais de refeições.

Recursos principais:

- mapa semanal de refeições;
- organização por dias e preparações;
- campos para composição e valores nutricionais;
- espaço para observações;
- estrutura editável para diferentes operações.

O arquivo foi criado como ferramenta de organização e deve ser preenchido e revisado pelo usuário conforme seu contexto.

## Arquivos incluídos

Planilha XLSX, guia em PDF e modelo DOCX.

## Observação

Os dados de exemplo são fictícios. A utilização deve ser revisada por profissional habilitado e adaptada às exigências aplicáveis.
