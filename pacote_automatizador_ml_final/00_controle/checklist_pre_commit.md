# Checklist antes do commit e do deploy

- [ ] Os 8 SKUs aparecem no `catalog-novos.json`.
- [ ] Cada SKU possui 3 imagens no diretório `images/`.
- [ ] Cada SKU possui texto em `03_anuncios_md`.
- [ ] Os títulos não prometem resultado garantido.
- [ ] As descrições não prometem envio, download ou acesso imediato.
- [ ] Não há nomes reais, universidades, clientes ou marcas de terceiros.
- [ ] Produtos de nutrição e saúde possuem observação educativa adequada.
- [ ] Produtos técnicos não usam alegações de conformidade sem comprovação.
- [ ] Os ZIPs permanecem fora do GitHub público.
- [ ] Categorias ainda serão selecionadas pelo preditor do Mercado Livre.
- [ ] Cada SKU será validado antes da publicação.
- [ ] O primeiro deploy será testado com apenas um produto.
